# BarberFlow — aplicativo

Aplicativo web e mobile desenvolvido com Expo, React Native e TypeScript.

## Executar localmente

Na pasta `app/`:

```powershell
npm install
npm run web
```

O aplicativo usa a API local por padrão. Para usar outra instância, configure `EXPO_PUBLIC_API_URL` no ambiente local.

Para instruções de configuração da API e informações de segurança, consulte o [README principal](../README.md).
